Selector(FAQ)
--------------------

css selectors are used to select the html element for styling.
you want select the html css provide number of selectors.

they divided into five categories
----------------------------------------
1.Simple selectors (select elements based on name, id, class)
2.Combinator selectors (select elements based on a specific relationship between them)
3.Pseudo-class selectors (select elements based on a certain state)
4.Pseudo-elements selectors (select and style a part of an element)
5.Attribute selectors (select elements based on an attribute or attribute value)

Simple selectors:
---------------------
Simple selectors are used to select elements based on their name, id, class.


How many ways write the css code?(FAQ)
---------------------------------------
you can write the css code three ways
1.inline css
2.internal css
3.external css

inline css: inline css means write the css code inside html element using style attribute.
ex:

<h1 style="color:red;background:pink">Java Full Stack</h1>


internal css: internal css means write the css code with in html file inside <style> tag.
<style> placed inside side <head> part.
